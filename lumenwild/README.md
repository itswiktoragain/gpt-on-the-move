# Lumenwild ✨

A Fabric dimension mod for **Minecraft Java 1.21.1**.

## Features

- The **Lumenwild Sky Archipelago**: three different tiers of floating continents, generated by a unique system of custom noise-density functions. No Overworld mountains, rivers, villages or oceans.
- **21 blocks:** the original nine plus aetherstone, polished aetherstone, aetherstone bricks, riftstone, riftstone bricks, shadow moss, star moss, halo crystal, crystal bloom, wispwood, wisp planks, and transparent skyglass.
- **Giant crystal spires** made by a procedural 3D structure algorithm, and **floating halo meteorites** that form in the gaps between the island strata.
- **Native rock and ore veins** growing inside aetherstone and riftstone; illuminated moss on the tops and dark cliff undersides.
- **Prism shards** and **umbral dust**, plus a prism sword, prism pickaxe, and permanent rift key.
- Procedurally generated original pixel-art textures.
- Crafting recipes, loot tables, mining tags, translations, and survival-world compatibility.

## How to enter

1. Find a vanilla **amethyst shard**, **glowstone dust**, **ender pearl**, and **crying obsidian** in the Overworld.
2. Craft a **Rift Key** using those four items. This fixes the previous progression deadlock where the key required ores only available inside the dimension.
3. Place **crying obsidian** and right-click it while holding the Rift Key.
4. The key sends you to Lumenwild and builds a small safe landing platform with a crying obsidian return anchor beside it.
5. Right-click the return anchor with the key to return to the Overworld. The key is reusable.

In Creative mode, all additions are in the Building Blocks, Natural Blocks, Combat, Tools, or Ingredients tabs.

## Install

Install Fabric Loader and Fabric API for Minecraft Java 1.21.1, then copy `lumenwild-1.1.0.jar` to your `.minecraft/mods/` folder.

**Backup existing worlds before adding or removing dimensions.** The world must load the mod to retain its dimension.

## Build from source

Requires JDK 21 and Gradle 8.9 (or let GitHub Actions build for you):

```bash
cd lumenwild
gradle build
```

The JAR will appear in `build/libs/lumenwild-1.1.0.jar`.
The `generateTextures` Gradle task creates all PNG assets automatically before resource processing.

## Source structure

- `src/main/java/dev/wiktor/lumenwild/LumenwildMod.java`: registration, entry logic, equipment.
- `src/main/resources/data/lumenwild/dimension`: dimension definition.
- `src/main/resources/data/lumenwild/worldgen`: custom biome and world-generation features.
- `src/main/resources/data/lumenwild/recipe`: survival recipes.
- `src/main/resources/assets/lumenwild`: textures generated at build time, block/item models, localizations.

No Mixins are needed for this mod.

## World generation algorithm (v1.1)

The terrain no longer uses Minecraft's overworld noise settings. Instead, `sky_archipelago.json` layers three **independent** 2D continental drift fields (undertow, drifts, crown) with clamped vertical gradients. A 3D turbulence/fracture field erodes their edges into cliffs, arches and irregular island undersides. Custom surface rules apply glowing moss to the upper islands and deep purple rock beneath. Java features place enormous branching crystal spires and floating halo-core meteorites.

**Existing worlds:** Create a fresh world to experience the complete floating islands, or travel to never-generated chunks after making a backup. Existing chunks are never regenerated just because the mod updates. The dimension's noise settings and dimension type have changed substantially.

**CI verification:** The build launches a genuine Minecraft dedicated server and samples generated Lumenwild terrain for native stone, elevated landmasses and void.
