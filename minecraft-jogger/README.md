# Minecraft Jogger

An Android launcher for Minecraft: Java Edition, being built for Wiktor.

## Project goals

- Run Minecraft Java on Android using the Amethyst/Pojav native runtime foundation.
- Microsoft device-code sign-in with a Java Edition account.
- Comfortable touch controls with a bundled Java touch agent.
- Separate game instances, mod-loader installation, resource packs and downloads.
- Per-instance Android home-screen shortcuts.

This branch contains the project and reproducible APK build. Minecraft game files are downloaded from their official sources after installation; they are not redistributed in this repository. This is an independent launcher, not an official Mojang or Microsoft product.

Build status: implementation in progress. This README will be updated with the APK, source provenance, exact supported features, and test results.
