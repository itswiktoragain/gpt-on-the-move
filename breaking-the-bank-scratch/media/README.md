# Breaking the Bank - lightweight TurboWarp version
Open BreakingTheBank_Lite.sb3 in https://turbowarp.org/editor .
When prompted, allow the custom Bank Stream extension from the main branch.
Hit the green flag. The original Flash animation streams from
BreakingTheBank.mp4 hosted in this branch.
Choose a branch by clicking the six original menu choices or pressing 1-6.
Press R to restart. This is TurboWarp-specific and needs internet;
regular Scratch does not support this custom extension.
Unlike the old 900-costume SB3, it contains only one image sprite.
Audio and branch selection are controlled by Scratch scripts.
