# Bullet — Fabric 1.21.4

A tiny rideable, craftable teleport machine with vanilla-feeling coordinate-entry UI.

## Install
Use Minecraft Java Edition 1.21.4 with Fabric Loader and Fabric API. Drop bullet-1.0.0.jar into the mods folder.

## Crafting
Iron | Redstone | Iron
Copper | Ender Pearl | Copper
Iron | Redstone | Iron

Place the crafted Bullet item by right-clicking the top of a block, then right-click the vehicle to sit in it.
A native coordinate screen will open. Enter X, Y, Z, then press DONE — LAUNCH.
FOV rises past Quake Pro to 720 with shaking, the vehicle and player teleport together,
and the camera eases back to normal. Sneak-right-click the empty vehicle to recover the item.

Note: very large real FOVs can invert/distort the perspective projection; this is intentional.
Server-side travel is only allowed from the vehicle's seat.
